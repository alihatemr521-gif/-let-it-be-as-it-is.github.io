# Let it be as it is

A cinematic personal website for writings, photos, and an archive.

## Current structure
- Writings
- Photos
- Archive
- English / Arabic interface toggle
- Responsive design for iPad, phone, and desktop
- User-supplied brain artwork in `assets/brain.gif`

## Important hosting note
This version is a static site. GitHub Pages can host it for free, but it does not provide a secure admin dashboard for publishing posts.

For a true "log in → write → publish" dashboard, the project needs a CMS/backend. That can be added as a second phase without changing the visual design.
